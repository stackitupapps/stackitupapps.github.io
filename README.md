# Stack It Up — Watch your savings grow

Created by Ayaan Bajaj.

A free pocket money tracker for students. Log what you spend and receive, set a monthly
budget, save up for goals, see charts of where your money goes, check if you can afford something, join savings challenges, take a money quiz, earn badges, create UPI payment QR codes and links, scan UPI QR codes to pay, and split bills with friends.

Private by design: all data stays on the user's own device (browser storage).
No sign-up, no server, no ads. Works offline once opened.

## Publish on GitHub Pages
1. Upload all these files to a public GitHub repository.
2. Settings → Pages → Branch: main, folder: / (root) → Save.
3. The site appears at https://YOUR-USERNAME.github.io/REPO-NAME/

## Contact
Use the Contact section on the About page of the site.

## Payments
Stack It Up never holds or moves money. It creates UPI payment QR codes and links, reads UPI QR codes,
and opens the user's own UPI app (GPay, PhonePe, Paytm...) to complete the payment. The UPI app confirms
the payment. Friends and groups are stored on the user's device only.
Libraries (included): qrcode-generator (MIT), jsQR (Apache-2.0).
